# RTN

Landing page draft. A real site becomes a simulation, so a buyer can see whether a robot can do the job there before buying it.

## Run locally

```bash
python3 -m http.server 4173
```

Then open http://localhost:4173. No build step and no dependencies.

## Structure

| Path | What it is |
|---|---|
| `index.html` | The page: hero, pinned scroll story, options A B C, process film, how it works, industry, contact |
| `quote.js` | The request-a-quote modal: step 1 is just an email (phone and company optional), step 2 adds site details. On the claude.ai share link it stores requests in the artifact's database; this repo has no backend, so it shows the confirmation without storing anything |
| `options.js` | The options A, B, C section: 1,219 designs narrowed to 3, a priority toggle with option cards, and station cycle times. Industrial engineering estimates, labeled on the page |
| `engine.js` | Canvas animation with no libraries: the capture dome in the hero, the six-stage scroll story, the small live views |
| `robots.js` | Robot motion for the hero and the scroll story (the H1 is the Unitree model from MuJoCo Menagerie, BSD-3-Clause): points on each body and body poses per frame, generated by `tools/export_robots.py` |
| `scan.js` | The CarDA WS30 station as points (12,583 points, 2 calibrated cameras, ground first, then the rest by rising height), behind the hero globe and the scroll story. Exported by `sim/sunny-isaac-sim/ws30_station/export_web_scan.py` in the robot repo from real IN and OUT frames with metric depth. CarDA, CC BY 4.0 |
| `dots.js`, `dots_data.js` | Story step 03: the WS30 door job as dots, a real worker's motion (CarDA, CC BY 4.0) beside two rail arms and two G1s on one real-time clock. Data from `export_dots.py` in the robot repo, packed by `tools/pack_dots.py` |
| `media/` | Our own simulation clips, plus a poster frame for each in `media/posters/` so tiles never start empty |
| `tools/export_scan.py` | Rebuild `scan.js` from a scan folder (`lidar_map.ply`, `poses.txt`, `mujoco/scene_info.json`) |
| `tools/export_robots.py` | Rebuild `robots.js` from MuJoCo: the real two-G1 carry run, plus a scripted Panda arm and Go2 |
| `tools/build_artifact.py` | Write `dist/index.html` for a claude.ai Artifact share link |
