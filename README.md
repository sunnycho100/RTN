# RTN

Landing page draft. A real site becomes a simulation, so a buyer can see whether a robot can do the job there before buying it.

## Run locally

```bash
python3 -m http.server 4173
```

Then open http://localhost:4173. No build step and no dependencies.

## Structure

| Path | What it is |
|---|---|
| `index.html` | The page: hero, pinned scroll story, process film, how it works, robots, industry, contact |
| `engine.js` | Canvas animation with no libraries: the capture dome in the hero, the six-stage scroll story, the small live views |
| `robots.js` | Robot motion for the scroll story: points on each body and body poses per frame, generated by `tools/export_robots.py` |
| `scan.js` | A real room scan (13,192 points, 118 camera poses, walls and clutter shapes), generated by `tools/export_scan.py` |
| `media/` | Our own simulation clips, used as placeholders until the final pipeline renders replace them |
| `tools/export_scan.py` | Rebuild `scan.js` from a scan folder (`lidar_map.ply`, `poses.txt`, `mujoco/scene_info.json`) |
| `tools/export_robots.py` | Rebuild `robots.js` from MuJoCo: the real two-G1 carry run, plus a scripted Panda arm and Go2 |
| `tools/build_artifact.py` | Write `dist/index.html` for a claude.ai Artifact share link |

## Media

All clips are our own runs. None come from other companies' sites.

| Clip | Source |
|---|---|
| `capture.mp4` | The floor4 scan's camera frames |
| `process_film.mp4` | Process film of the same scan, video frames to a walking G1 (Mac render; clean walls and camera moves are styling) |
| `walk.mp4`, `coop_carry.mp4` | MuJoCo: G1 walking in a reconstructed scene, two G1s carrying one box |
| `h1_photoreal_room.mp4`, `h1_warehouse.mp4`, `h2.mp4`, `spot.mp4`, `go2.mp4`, `anymal.mp4` | Isaac Sim locomotion runs |
| `ur10_palletizing.mp4`, `ur10e_pick_place_cumotion.mp4`, `franka_policy.mp4` | Isaac Sim manipulation runs |
| `g1coop_factory.mp4` | Seohee's 20-robot factory: her MuJoCo run rendered in Isaac Sim (visual port, MuJoCo decides all motion) |
| `carda_line.mp4` | Car-door line, option C: kinematic replay, UR10e as a visual stand-in for the Doosan M0617 |
| `factory_workflow.mp4` | Factory workflow simulation: metal shop, 15 robots (15 s cut) |

The Isaac Sim clips use NVIDIA's sample robot and environment assets. Credits: CarDA motion capture (CC BY 4.0) in `carda_line.mp4`, and roqsim's Depot warehouse (CC BY 4.0) in `g1coop_factory.mp4`.

CooHOI clips (NeurIPS 2024, no license file) are never committed. They sit in the git-ignored `private/` folder with a `tiles.html` snippet, and `tools/build_artifact.py` adds them to the private share link only.
