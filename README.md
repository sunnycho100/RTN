# RTN

Landing page draft. A real site becomes a simulation, so a buyer can see whether a robot can do the job there before buying it.

## Run locally

```bash
python3 -m http.server 4173
```

Then open http://localhost:4173. No build step and no dependencies.

## Structure

| Path | What it is |
|---|---|
| `index.html` | The page: hero, pinned scroll story, how it works, robots, industry, contact |
| `engine.js` | Canvas animation with no libraries: the capture dome in the hero, the six-stage scroll story, the small live views |
| `scan.js` | A real room scan (13,192 points, 118 camera poses, walls and clutter shapes), generated by `tools/export_scan.py` |
| `media/` | Our own simulation clips, used as placeholders until the final pipeline renders replace them |
| `tools/export_scan.py` | Rebuild `scan.js` from a scan folder (`lidar_map.ply`, `poses.txt`, `mujoco/scene_info.json`) |
| `tools/build_artifact.py` | Write `dist/index.html` for a claude.ai Artifact share link |
